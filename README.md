# 🇮🇳 15 August — Independence Day

A beautiful, responsive **Indian Independence Day** celebration webpage built using **HTML and CSS**. The design uses the colors of the Indian tricolor, smooth layouts, responsive cards, and a CSS-created Indian flag with Ashoka Chakra styling.

## ✨ Features

* 🇮🇳 Independence Day themed design
* 🎨 Indian tricolor-inspired color palette
* 📱 Fully responsive layout
* 🧭 Navigation with smooth scrolling
* 🏠 Hero section with Independence Day message
* 💬 Dedicated message section
* 🏆 Values section highlighting:

  * Unity
  * Courage
  * Progress
* 🚩 CSS-based Indian flag illustration
* 💫 Hover animations and modern card effects
* 📐 Responsive breakpoints for tablets and mobile devices
* 🚫 No external libraries or frameworks required

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* CSS Grid
* CSS Flexbox
* CSS Gradients
* CSS Animations & Transitions
* Responsive Media Queries
* Emoji-based visual elements

## 🎨 Design

The webpage uses a modern glassmorphism-inspired interface with:

* Saffron `#ff9933`
* White `#ffffff`
* Green `#138808`
* Navy `#0b1f3a`

The background, buttons, cards, and decorative elements are styled using CSS gradients, shadows, transparency, and rounded corners.

## 📱 Responsive Design

The layout automatically adapts to different screen sizes.

### Desktop

The hero section uses a two-column layout, while the values section displays three cards side-by-side.

### Tablet

The hero and cards switch to a single-column layout on smaller screens.

### Mobile

The navigation becomes vertically arranged, buttons span the available width, and the flag illustration is reduced to fit smaller displays.

## 🧩 Sections

### Home

The hero section introduces the Independence Day theme with a greeting, description, call-to-action buttons, and statistics such as **79 Years of Freedom** and **1 India, One Nation**.

### Message

A dedicated section shares an Independence Day message focused on courage, compassion, unity, and love for India.

### Values

The website highlights three values:

| Value           | Description                                     |
| --------------- | ----------------------------------------------- |
| 🇮🇳 **Unity**  | Standing together as one nation                 |
| 💪 **Courage**  | Remembering those who fought for freedom        |
| 🌱 **Progress** | Building a future based on hope and development |

These cards are implemented directly in the HTML and styled with CSS.

## 🚩 CSS Flag Illustration

The Indian flag is created entirely with CSS rather than using an external image. It uses three horizontal color bands and a circular Ashoka Chakra element positioned in the center.
